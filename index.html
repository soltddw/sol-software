01 // INTRODUCCIÓN

Contexto y Propósito del Informe

  • Objetivo principal: Consolidar los conceptos explicados en el video sobre la creación, estructuración y publicación de aplicaciones web estáticas.
  • Enfoque analítico: Transformación de código alojado en una computadora local a un entorno en vivo disponible en la red.
  • Metodología: Uso de herramientas modernas como HTML5, CSS3, control de versiones mediante Git/GitHub y servidores en la nube como Render.
02 // ARQUITECTURA

Pilares Tecnológicos

[HTML]

Estructura Semántica

  • Jerarquía clara con etiquetas modernas.
  • Accesibilidad para lectores de pantalla.
  • Indexación optimizada para buscadores (SEO).
[CSS]

Estilizado Visual

  • Paleta de colores menta y esmeralda.
  • Variables CSS para mantener consistencia.
  • Diseño totalmente adaptable (Responsive).
[GIT]

Control de Código

  • Historial seguro de cambios en el proyecto.
  • Respaldo remoto en la nube con GitHub.
  • Gestión eficiente mediante commits.
[CLOUD]

Publicación Automática

  • Sincronización directa desde el repositorio.
  • Generación de enlace público con HTTPS.
  • Despliegue continuo sin costo.
